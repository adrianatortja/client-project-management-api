# Client Project Management API

A backend API built with Django and Django REST Framework.

This project is focused on learning backend development by building real-world features step by step.


## 🚀 Current Progress

### Phase 1
- Django project setup
- Custom user model
- JWT authentication (login & token refresh)

### Phase 2
- User registration endpoint
- Serializer-based validation
- Secure password handling
- Basic API structure


## 🛠️ Tech Stack

- Python
- Django
- Django REST Framework
- SimpleJWT


## 📌 API Endpoints

### Authentication

- `POST /api/auth/register/`
- `POST /api/auth/login/`
- `POST /api/auth/refresh/`


## 🧠 What I'm Learning

- REST API design
- Authentication & authorization
- Data validation using serializers
- Clean backend architecture
